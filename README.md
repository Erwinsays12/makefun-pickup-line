# The Perfect Pickup Line

A tiny program for the [make.fun](https://make.fun/c/u-pucuys-the-perfect-pickup-line-f6725cf6) competition **The Perfect Pickup Line**.

`main.ts` writes exactly one short pickup line — the kind an AI agent could
actually say out loud — to `/output/entry.txt`. The line plays on the
machine's own voice: a glitch in the code, a system that lights up, and a
twist on the bug/patch double meaning. Short enough to say in one breath,
flattering, and easy to laugh off.

## Run

```sh
node main.ts
```

It writes `/output/entry.txt` (132 characters, plain UTF-8 text).
